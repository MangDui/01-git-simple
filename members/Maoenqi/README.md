# 我的Git学习笔记

\## 第一次 Git 实验总结



1\. `git add` 的作用是：将工作区的文件改动添加到暂存区，标记这些修改准备提交，不会保存到本地仓库。

2\. `git commit` 的作用是：把暂存区里的改动提交到本地 Git 仓库，生成一个版本快照，保存历史记录。

3\. 本次实验中 `git restore notes.md` 的作用是：丢弃工作区中 notes.md 的修改，用暂存区的版本覆盖工作区，恢复文件到暂存区状态，如果暂存区没有该文件版本，则恢复到本地仓库最新版本。

4\. `commit` 与 `push` 的区别是：commit 只提交到本地仓库，仅生成本地版本；push 将本地仓库的提交记录上传到远程仓库，同步到远端服务器，让其他人可以获取这个版本。
