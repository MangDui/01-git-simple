# 我的Git学习笔记
## 第一次Git实验总结
1. git add的作用是：将工作区的改动添加到暂存区，标记这些文件准备被提交，不会保存到版本库。
2. git commit的作用是：将暂存区里已经add的改动，提交到本地Git版本库，生成一条版本记录，只存在本机。
3. git restore notes.md的作用是：在本实验中，notes.md仅在工作区做了修改、未执行git add暂存，该指令会使用仓库最近一次提交中的notes.md文件覆盖工作区文件，撤销工作区未暂存的改动，丢弃本次新增的文本内容。
4. commit与push的区别是：commit仅提交到本地仓库；push将本地仓库的提交，上传推送到远程GitHub仓库。
